Quillgeist

Reduce repeated instruction and execution work between people, AI models, and local tools.

People repeatedly restate goals, preferences, constraints, tool details, and definitions of done. They also send work to external models that could be executed locally. Quillgeist is being built as an adaptive layer between user intent and the system doing the work.

Improve
Turn normal-language intent into a clearer instruction.Goal, constraints, tools, context, and definition of done are made explicit for the model or tool being used.
Route
Separate local execution from external reasoning.Eligible deterministic work can run locally while the parts that need model reasoning are routed outward.
Learn
Use corrections and outcomes to reduce repetition.The adaptive layer is being developed to learn from accepted edits, rejected edits, preferences, and task outcomes.
Verify
Return evidence against the definition of done.Execution should produce inspectable results rather than a vague claim of completion.
LandThePlane

The interview-prep wedge is the evidence graph, not generated questions.

A resume and a job description are only inputs. The durable asset is a candidate-owned map of verified accomplishments, role requirements, answer formats, interview history, edits, and outcomes.

Founder-use loop

Dogfood happens during real preparation.

Each prep session, interview, and debrief can expose a product gap without inventing a separate test workflow.

Competition risk

Generic AI coaching is already crowded.

The product only deserves priority if evidence traceability, longitudinal learning, and answer compression create repeat use that generic resume + JD tools do not.

Promotion gate

Make users decide the flagship.

External candidates need to return across rounds, reuse their evidence, and show willingness to pay or refer before LandThePlane moves above Quillgeist.

Flagship rule

Do not switch because the new idea feels easier.

LandThePlane should become flagship only if it wins quickly on external repeat use, evidence reuse across rounds, paid pull or strong referrals, and a resolved standalone name.

What to learn next

Which product earns repeated behavior?

For Quillgeist: repeated daily workflow use. For LandThePlane: repeated use across interviews, rounds, and roles because the saved evidence becomes more valuable over time.
