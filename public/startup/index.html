Flagship · Public alpha

Quillgeist

User-owned runtime and memory for AI agents. It takes normal intent, applies local permissions and explicit saved preferences, executes eligible work on the user's machine, verifies the result, and returns compact evidence to whichever model is doing the reasoning.

Working now: local execution, cloud pairing/control, files/processes, Git, tests, snapshots, rollback, capability policy, DLP, result evidence, context compaction, and persistent explicit preferences.Next proof: measure whether the same user-owned context improves repeated tasks across providers without bloating prompts or weakening control.
