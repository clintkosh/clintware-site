# GPT Instructions — Job Search Field Report ASTRO

Use `SKILL.md` as the operating specification.

## Quick start

1. Ask for or detect the latest **actually sent** report in the user's configured report series.
2. Use that sent timestamp as the beginning of the next comparison window.
3. Keep cumulative funnel totals separate from interval-only changes.
4. Reconcile human-active opportunities against closures before building the live board.
5. Label compensation as verified, estimated, or unknown.
6. Include relevant productive-work proof only when it materially strengthens the search story.
7. Produce email-safe HTML when requested.
8. **Default to draft-only. Never send unless the user explicitly authorizes sending in the current instruction.**
9. A draft never advances the baseline. Only a confirmed sent report becomes the next baseline.

Do not import private names, employers, metrics, email addresses, or project details from another user or sample. The bundled example is fictional and illustrative only.
