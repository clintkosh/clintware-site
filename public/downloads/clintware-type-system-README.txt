CLINTWARE TYPE SYSTEM
Version 1.0 — 2026-09-23

WHAT THIS IS
A CSS typography system used by Clintware.com. It combines:
- Clintware Sans: readable Arial/Helvetica-compatible sans stack.
- Clintware Display: compact software-oriented heading stack.
- Clintware Mono: terminal/code/metadata stack.
- Clintware Hand: optional annotation-only fallback stack.
- Clintware Alien: subtle CSS styling utility for occasional alternate display text.

IMPORTANT
This package does not contain or redistribute Arial, Helvetica, Cascadia Code, Segoe Print, or other proprietary font binaries.

OPEN-SOURCE BASE OPTION
Liberation Sans and Liberation Mono are open fonts designed for metric compatibility with common Microsoft fonts. Liberation Fonts 2.x is licensed under the SIL Open Font License 1.1:
https://github.com/liberationfonts/liberation-fonts/releases

USAGE
1. Download clintware-type-system.css.
2. Link it in your page:
   <link rel="stylesheet" href="clintware-type-system.css">
3. Use normal headings/body text, plus optional classes:
   .cw-mono
   .cw-hand
   .cw-alien
   .cw-brand-accent
