Modular by what is installed

7-Zip controls appear only when 7-Zip is detected. Windows Terminal and PowerShell integrations follow the same rule. Registry-backed shell verbs are discovered dynamically instead of hard-coded as a fake inventory.

WINDOWS 11

Compact or classic menu

Switch between the Windows 11 compact menu and the classic full menu. Traditional registry verbs may remain under “Show more options” while compact mode is active.

Safety boundary

The manager will not blindly unregister unknown COM context-menu handlers. Those are inventory-only. Ordinary registry-backed verbs use per-user overrides where possible, and Clintware records the pre-change state before Apply.
