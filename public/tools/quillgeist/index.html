Quillgeist improves AI requests and runs routine work locally.

How it works

Four steps between a request and a result.

1 · WriteDescribe what you want in normal language.
2 · ImproveClarify the goal, constraints, tools, and completion criteria.
3 · RouteRun routine work locally and send only reasoning-heavy work to a model.
4 · LearnUse corrections, accepted changes, preferences, and outcomes to improve future requests.
Product state

Working execution layer. Adaptive learning layer in active development.

Working in the public alpha

  • Local execution on Windows, macOS, and Linux.
  • Execution packs with permissions, constraints, steps, and completion checks.
  • Local allow / ask / never capability policy.
  • Filesystem, process, Python, PowerShell, Node.js, Git, tests, scheduling, and rollback support.
  • Compact result packages with evidence of what ran and changed.
  • Account-scoped execution history.

In active development

  • Instruction improvement while the user writes.
  • Preference memory from accepted, rejected, and edited suggestions.
  • Recognition of repeated workflows.
  • Routing based on task type, local capability, policy, and model need.
  • Evaluation against a clear definition of done.

YOU
"Update the release, run the checks, fix routine failures,
and only bring me back decisions that need judgment."

QUILLGEIST
local: files · commands · tests · retries · evidence
model: ambiguous failures · judgment · final explanation
done: checks pass + changed files verified + blockers surfaced
