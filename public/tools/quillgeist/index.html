Quillgeist

User-owned runtime and memory for AI agents.

Quillgeist lets AI agents safely do work on your computer, verify what actually changed, and reuse your explicit preferences across models. The model can change. Your local permissions, operating context, and evidence stay with you.

Open public alphaWindows installer

The proof loop

INTENTState the goal normally.
POLICYResolve permissions, privacy, context, and definition of done.
EXECUTERun eligible deterministic work on the user's machine.
VERIFYReturn checks, changed-file evidence, failures, and recovery state.
REMEMBERKeep explicit user-approved preferences locally for the next model or task.

Working today

Local runtime
Windows, macOS, and Linux execution.Filesystem, processes, Python, PowerShell, Node.js, Git, tests, schedules, snapshots, and rollback.
User memory
Explicit preferences persist outside a model provider's chat history.Use remember: to save a rule locally. Future compiled instructions include it, even when the connected AI changes. Direct task instructions override saved preferences.
Policy
Allow / ask / never capability controls remain locally authoritative.Sensitive-data checks run locally before eligible execution, external routing, and preference persistence.
Verification
“Done” is evidence, not a model claim.Results can include checks, outputs, changed files, snapshots, rollback state, and Definition-of-Done evidence.
Context
Compact execution noise before sending it back to a reasoning model.Contextor preserves useful errors and completion evidence while tracking estimated context and external tokens avoided.

Cross-model memory MVP

1. Correct Quillgeist once.
remember: Keep the original file and create a copy
2. Start a later task with any connected model.
Update this source file with the corrected content.
3. Quillgeist injects the saved user-owned preference before the task leaves the local intent layer.

The point is not another chatbot memory feature. The preference belongs to the user's Quillgeist runtime rather than to one model provider.

What still has to be proven

Explicit preference persistence is now implemented. The larger adaptive thesis is still a product question: can Quillgeist reliably identify which user-approved context is relevant, reduce repeated instruction over sustained use, and improve outcomes without creating another bloated system prompt? That is the next measurement target.
