Three layers, one product.

Quillgeist WorkspaceThe human SaaS layer: one prompt, model switching, sub-search fan-out, synthesis, saved browser-local routing state, usage/evidence surfaces.
Quillgeist Lite / QQThe local execution layer on machines such as MEMORIA and DRIZNET: reviewed tasks, adaptive CPU/RAM/GPU workers, health, verification, and local models.
Clintware MCPThe authority and interoperability layer: capability discovery, credentials behind the boundary, scoped external actions, handoffs, and evidence.
Privacy boundary: The public workspace does not receive or store provider credentials. Local/private execution remains local unless an authorized router deliberately sends a bounded branch elsewhere.

Designed for model switching, not model lock-in.

A primary synthesis model does not have to be the same model used by every sub-search. Quillgeist owns the dependency graph and final evidence contract.
