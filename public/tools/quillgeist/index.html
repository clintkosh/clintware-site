Start here

Install. Pair. Run.

01 / INSTALL
Download Quillgeist

On Windows, download Quillgeist-Windows-x64.exe. The executable contains the local node runtime; you do not need to install the Python package manually.

02 / PAIR
Connect this computer

Run Quillgeist-Windows-x64.exe init, then pair. Enter the short pairing code in Quillgeist Cloud.

03 / RUN
Give it work

Quillgeist applies local policy, executes eligible work, verifies completion, and returns a compact result with what changed and what still needs judgment.

Windows quick start

Four commands to bring the node online.

Run these from PowerShell in the folder containing the downloaded executable.

.\Quillgeist-Windows-x64.exe init
.\Quillgeist-Windows-x64.exe doctor
.\Quillgeist-Windows-x64.exe pair --cloud https://quillgeist.clintware.com
.\Quillgeist-Windows-x64.exe daemon
What works now

A real local execution layer, not a browser-only demo.

Local execution
  • Windows, macOS, and Linux node builds.
  • Filesystem and process execution.
  • Python, PowerShell, Node.js, and Git.
  • Tests, schedules, snapshots, and rollback.
  • Local allow / ask / never capability policy.
  • Sensitive-data checks before eligible execution and routing.
Cloud control + evidence
  • Pair computers to a Quillgeist account.
  • Dispatch work to a selected local node.
  • Review execution history and verified results.
  • Compact large execution output before returning it upstream.
  • Account-scoped operational telemetry without prompt/file contents.
  • Adaptive instruction learning remains under active development.

Quillgeist is the product name everywhere.

The former AgentBridge name is retained only as a temporary internal/CLI compatibility alias for early alpha state. New installs, endpoints, binaries, file associations, docs, and public-facing flows use Quillgeist.
