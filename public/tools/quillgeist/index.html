Quillgeist

Adaptive intent compiler for AI.

Quillgeist turns normal user intent into a clearer execution plan, routes eligible deterministic work to the user's own machine, verifies what happened, and is being built to learn from corrections so less context has to be repeated over time.

Open public alphaWindows build

Product loop

TYPEState the goal normally.
UNDERSTANDResolve context, constraints, tools, permissions, and definition of done.
IMPROVEPrepare the instruction the target model or tool actually needs.
EXECUTERun eligible work locally and return evidence.
LEARNUse corrections and accepted outcomes to reduce repetition over time.

Working today

Local node
Windows, macOS, and Linux execution.Filesystem, processes, Python, PowerShell, Node.js, Git, tests, schedules, snapshots, and rollback.
Cloud control
Pair a machine, dispatch work, inspect execution history and results.The cloud coordinates; the local node performs eligible work under capability policy.
Policy
Allow / ask / never controls for execution capability.Sensitive-data checks and explicit capability boundaries are part of the current alpha.
Evidence
Completion includes checks, outputs, changed files, and recoverability where applicable.“Done” should be inspectable rather than a model claim.

Still in development

Adaptive preference and instruction learning are not presented as finished. The next product proof is whether accepted edits, rejected edits, corrections, and outcomes measurably reduce repeated instruction in sustained real use.
