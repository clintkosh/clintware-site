Install

  1. Download and extract v1.1.0.
  2. Open edge://extensions or chrome://extensions.
  3. Enable Developer mode.
  4. Select Load unpacked and choose the folder containing manifest.json.
Current route

Run

  1. Select Find followed companies.
  2. On LinkedIn, reopen the extension and select Scan.
  3. Select company Pages or choose all.
  4. Start the run and stop at any time.
