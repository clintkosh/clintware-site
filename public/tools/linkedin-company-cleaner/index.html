01 · Install
  1. Download the v1.1.1 ZIP and choose Extract All.
  2. Open the extracted folder and verify that manifest.json is directly visible.
  3. Optionally run VERIFY-AND-OPEN-EXTENSIONS.cmd.
  4. Open edge://extensions or chrome://extensions, enable Developer mode, choose Load unpacked, and select that exact folder.
02 · Run
  1. Select Find followed companies.
  2. On LinkedIn, reopen the extension and select Scan.
  3. Select company Pages or choose all.
  4. Start the run and stop at any time.
03 · Test result

The release was extracted into a clean directory, its root-level manifest and declared resources were verified, and Chromium successfully packed that exact directory. Scan, Select All, Start, Stop, direct-unfollow, confirmation-dialog, and missing-script recovery also passed with zero failures.

Install note. Do not select the ZIP itself, your Downloads folder, or a parent folder. Load unpacked must point to the exact extracted directory where manifest.json is visible.
Compatibility notice. This independent tool is not affiliated with or authorized by LinkedIn. LinkedIn can change its interface without notice, so selectors may require maintenance in later releases.
