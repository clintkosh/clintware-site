LinkedIn Company Cleaner

Bulk or selectively unfollow company Pages without touching people, schools, newsletters, groups, or skills. Version 1.1.3 fixes the dead Scan-button upgrade case by verifying the active LinkedIn worker and automatically reinjecting the current listener when an old tab has gone stale.

01 · Install
  1. Download v1.1.3 and choose Extract All.
  2. Open the extracted folder. manifest.json must be directly visible.
  3. Open edge://extensions or chrome://extensions.
  4. Enable Developer mode, choose Load unpacked, and select that exact folder.
02 · Run
  1. Select Find followed companies.
  2. On LinkedIn, reopen the extension and select Scan.
  3. Select company Pages or choose all.
  4. Start the run and stop at any time.
03 · Release checks

The final v1.1.3 ZIP was extracted into a clean directory and tested from that extraction. The stale old-worker condition was deliberately reproduced; Scan recovered automatically and returned two company rows. Packaging, Scan, Select All, Start, Stop, direct unfollow, dialog unfollow, and exact navigation all passed: 40/40.
