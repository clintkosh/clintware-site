LinkedIn Company Cleaner

Bulk or selectively unfollow company Pages without touching people, schools, newsletters, groups, or skills. Version 1.1.2 removes all optional icon dependencies and ships with a flat extraction layout so the folder selected by Load unpacked directly contains manifest.json.

01 · Install
  1. Download the v1.1.2 ZIP and choose Extract All.
  2. Open the extracted folder. manifest.json must be directly visible.
  3. Optionally run VERIFY-AND-OPEN-EXTENSIONS.cmd.
  4. Open edge://extensions or chrome://extensions, enable Developer mode, choose Load unpacked, and select that exact folder.
02 · Run
  1. Select Find followed companies.
  2. On LinkedIn, reopen the extension and select Scan.
  3. Select company Pages or choose all.
  4. Start the run and stop at any time.
03 · Release checks

The final ZIP itself was extracted into a clean directory and then tested. Root manifest, every manifest-declared resource, no-icon assertions, JavaScript syntax, Chromium manifest parsing, popup actions, exact LinkedIn navigation, direct unfollow, and confirmation-dialog unfollow all passed.

Install note. v1.1.2 intentionally declares no extension icons, eliminating the Edge icon-loading failure seen in v1.1.1.
Compatibility notice. This independent tool is not affiliated with or authorized by LinkedIn. LinkedIn can change its interface without notice, so selectors may require maintenance in later releases.
