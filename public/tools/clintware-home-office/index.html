PRODUCT TRUTH

What exists today

Desktop

Tabbed Qt Writer alpha with rich text formatting and local files.

Formats

Open DOCX, HTML, text, and Markdown. Save DOCX, HTML, text, and Markdown. Export PDF.

Portable

Single-file browser editor with local recovery, local file open, HTML/text/Word-readable .doc export, and print-to-PDF.

Installer

Windows packaging and installer automation are implemented in the project build path. Public installer release depends on successful Windows build verification.

Boundary: Writer alpha is not presented as a complete Microsoft Office replacement or as pixel-identical Word compatibility.

WHY BUILD IT

The opportunity is not that free office suites do not exist.

LibreOffice, Apache OpenOffice, ONLYOFFICE, and browser tools already cover large parts of the market. Clintware Home Office is testing a narrower idea: a smaller, cleaner local-first office experience with a modern native shell and a portable editor that can run from one file.
