Flagship public alpha · Local execution bridge

Let your AI think. Let your computer do the work.

AgentBridge gives ChatGPT, Claude, Gemini, Grok, local models, or any other planner a common handoff format. The model creates an Execution Pack once. AgentBridge routes it to your own machine, enforces your local permissions, executes it, validates the result, and sends back a compact Result Pack.

Core rule

The cloud never becomes your admin shell.

AgentBridge Cloud can request work. The local Node decides whether that work is always allowed, requires approval, or is forbidden. A remote approval can satisfy a local ask; it cannot override local never.

Owner controls authority.
Execution stays on the user's computer. Cloud is the broker, scheduler, dashboard, and feedback route.
One loop

Planner → Pack → Node → Result.

The expensive model does not need to remain attached to a console. AgentBridge collects the execution evidence locally and sends only the useful result back.

1 · PlannerYour LLM creates a portable task.
2 · Execution Pack.abpack, AgentBridge JSON, or Markdown.
3 · Local NodePython, PowerShell, shell, Node.js, Git, and governed files.
4 · ContextorDeduplicates noisy logs before transmission.
5 · Result PackTests, changes, errors, Definition of Done, and rollback evidence.
Implemented alpha

A real execution bridge, not a simulated agent.

The alpha is intentionally narrow. It proves the handoff and feedback loop while keeping privileged decisions on the Node.

Cross-device scheduling

Run where the work belongs.

Schedules can be cloud-owned or device-owned. Cloud-owned schedules dispatch when due. Device-owned schedules sync down and continue locally when the Node is available. Move a schedule between paired machines from the dashboard.

Device-owned schedules that cross a local ask boundary require local schedule approval. This prevents creating a cloud schedule from becoming permanent remote admin permission.

Try the control plane, then pair a Node.

The public alpha uses an account key rather than production OAuth. Node builds are unsigned early-access binaries. Review packs and local permissions before elevated use.
