Flagship public alpha · Token offload + local execution

Stop paying the LLM to watch your computer work.

AgentBridge lets the model plan the task, then moves the repetitive execution loop onto your own machine. The local Node runs commands, handles allowed retries and checks, and Contextor removes noisy output before anything goes back upstream. The LLM receives a compact Result Pack instead of a full terminal transcript, reducing token use and API cost.

The basic idea

Model plans. Machine executes. Model gets the useful result.

AgentBridge is built to keep cheap, mechanical work out of expensive model context. Local policy still controls what the machine is allowed to do.

Local authority stays local.
Cloud can route a job, but the Node decides whether it can run.
Why it saves tokens

Move the noisy middle out of the LLM conversation.

The model should spend tokens on decisions and reasoning, not on reading every command response and repeated log line.

1 · PlanThe LLM defines the task and completion criteria once.
2 · HandoffAgentBridge packages and routes the task.
3 · ExecuteYour machine runs the allowed commands, file work, tests, and retries.
4 · CompactContextor removes duplicate and low-value output locally.
5 · ReturnThe LLM gets the result, useful evidence, and only the errors that need reasoning.
Token economics

Less raw output sent to the model means less paid context.

The exact savings depend on the task and model, so AgentBridge measures net token reduction instead of promising a fixed percentage.

Without AgentBridge

  • LLM issues a command.
  • Raw output returns into model context.
  • LLM reads logs, decides next command, and repeats.
  • Tests, retries, and verification can keep expanding the conversation.

With AgentBridge

  • LLM sends the job and completion criteria.
  • Local Node performs the mechanical execution loop.
  • Contextor compacts large or repetitive output before transmission.
  • Result Pack sends back the smaller set of facts needed for the next decision.
Implemented alpha

The token-saving loop is already part of the product.

The current alpha focuses on local execution, compact feedback, measurable savings, and local control.

AgentBridge NodeCross-platform Python core, pack parser, workspace containment, capability policy, rollback snapshots, local schedules, cloud pairing, command execution, checks, and Result Packs.
ContextorPass-through for small results, deterministic compaction for large logs, optional local Ollama smart compaction, and net token-savings telemetry.
Learning directionCorrection memory and useful-evidence learning are designed to make future handoffs smaller and more relevant over time. These learning features are still being developed.

Why local execution matters

The machine can do more without consuming more model turns.

Once a task is handed off, the Node can perform authorized deterministic work locally. The model only needs to come back into the loop when its reasoning is actually useful.

The Node still applies local allow / ask / never policy before execution, so reducing model involvement does not mean giving the cloud unrestricted access.
