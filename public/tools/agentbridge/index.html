Flagship prototype · Human-taught workflow intelligence

Teach it the work once. Correct it when it is wrong.

AgentBridge turns repetitive computer work into reusable AI workflows that improve from the user's corrections. Contextor learns how much context that user actually needs, reducing avoidable token spend without silently discarding what the user chose to keep.

One narrow wedge

Learn the user's operating method, not another generic automation recipe.

The first version deliberately avoids becoming an integration marketplace or general agent platform. It tests whether a system can learn what the user does, what “done” means, which corrections recur, and which context consistently earns its token cost.

1 · LearnCore

Workflow Learner

Capture a repeated task as explicit steps with a measurable Definition of Done. The longer-term product observes this work directly; this prototype starts with user-taught steps.

2 · ImproveCore

Correction Memory

Corrections become part of the workflow manifest instead of disappearing into chat history. Repeated changes become reusable operating knowledge.

3 · CompressContextor

Personal context weighting

Contextor starts conservatively: every context line is visible and user-controlled. Local history learns what this user repeatedly keeps or removes and adjusts future defaults.

Working browser prototype

Teach a workflow and train Contextor.

No prompt, workflow, or correction leaves the browser in this prototype. It performs no external writes and uses no paid model. Token counts are clearly labeled estimates.

Prototype boundary: Contextor learns from explicit keep/remove decisions. Semantic generalization, live application observation, model routing, and autonomous execution are roadmap items, not claims of this build.
