ShoulderSoldier

A user-interaction firewall for social engineering. The current build evaluates risky email, browser, message, and AI-agent interactions before a user takes the dangerous action, then explains why additional friction may be warranted.

Run evaluatorDiscuss a pilot

Working now

Four channels
Email, browser/web, messages/chat, and AI-agent requested actions.The same interaction model can evaluate the point where a person is being asked to click, send, install, pay, disclose, grant, or execute.
Explainable signals
Deterministic heuristics name the reason for added friction.Current signals include credential requests, urgency pressure, payment changes, remote-access or execution requests, sensitive-data transmission, authority bypass, high-risk attachments, suspicious URL structures, and agent external actions.
Proportionate action
Risk tiers map to different intervention levels.Low, caution, elevated, and high scores produce recommendations ranging from normal caution to independent verification before acting.
Agent boundary
An AI agent requesting an external action is not automatically treated as malicious.Agent-triggered send, payment, delete, install, privilege, or publish actions receive a modest confirmation signal that combines with other evidence rather than deciding the outcome alone.
Current boundary: this is deterministic decision support, not a claimed production phishing-detection model. It does not automatically block messages or actions, and a zero heuristic score is not proof that an interaction is safe.

What must be proven next

Detection value
Test against real labeled social-engineering and legitimate interaction sets.Measure recall, false positives, signal usefulness, and which interventions users actually follow.
Point of action
Move from paste-and-evaluate to an integration where risk is assessed at the actual interaction boundary.Browser, email-client, messaging, and agent-action integrations should be pursued only where privacy and permission boundaries remain explicit.
Category
Prove that “interaction firewall” is broader and more useful than another email warning product.The venture becomes interesting if one policy/evidence layer can protect human actions across providers and AI agents without training users to ignore constant warnings.
