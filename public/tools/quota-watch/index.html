Local-first quota status

Keep quota visible without inventing the numbers.

A standalone implementation of the Running Quota Notification Icon skill. Track a configured limit locally, import an exact snapshot from an official source, move configuration with CSV, and get threshold alerts. No account, backend, telemetry, or stored credentials.

If a service does not expose quota to this page through an official API or integration, QuotaWatch labels locally tracked values as Estimated. It never presents guessed values as exact.
