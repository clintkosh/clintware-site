CLINTWARE™ · TYPE SYSTEM

Readable first. Distinctive second.

The Clintware type system is built for software, documentation, product pages, and technical interfaces. It keeps familiar Arial/Helvetica proportions, adds a compact display voice, reserves monospace for system language, and uses handwritten or alien styling only as restrained accents.

Clintware Sans
Build software that earns its place.

Primary reading face. Arial/Helvetica-compatible proportions with Liberation Sans as the open-source first choice when installed.

Clintware Display
Go Furthest.™

Headings and compact product titles. Narrower, denser, and more software-oriented without becoming decorative.

Clintware Mono
