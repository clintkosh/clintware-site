Product state

A working execution layer with the adaptive layer in active development.

Working functionality and roadmap functionality are labeled separately.

Working in the public alpha

  • Local execution on Windows, macOS, and Linux.
  • Permission-aware execution packs with completion checks.
  • Filesystem, process, Python, PowerShell, Node.js, Git, tests, scheduling, and rollback support.
  • Compact result packages with evidence of what ran and what changed.

In active development

  • Real-time instruction improvement while the user writes.
  • Memory from accepted, rejected, and edited suggestions.
  • Reusable patterns for repeated workflows.
  • Routing based on task type, local capability, policy, and model need.
  • Evaluation against an explicit definition of done.
WHY

The same correction should not need to be repeated every time.

People repeatedly rewrite prompts, restate preferences, and pay for model context to perform work their own computer could handle. Quillgeist is being built to reduce that repetition.
