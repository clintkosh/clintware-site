# N7 Demo CRM

Clintware-native Customer Success / Implementation / ROI CRM for the Neuron7 case.

- Runtime: Cloudflare Worker + Durable Objects SQLite.
- No third-party visual app-builder runtime, SDK, generated dependency, or deployment dependency.
- Target: https://n7demo.clintware.com
- Initial account is seeded only from the official case facts.
- The Clinton Kosh case-study response is treated as internal proposed plan/design material.
- Unknown customer values remain blank or Not provided.
- AI is optional and belongs behind a future Clintware control-plane provider; Exa is never called from the browser.

Core modules: command center, handoff, implementation, risk/escalation, ROI, adoption, issue triage, meetings/briefs, renewal/value, documents/import, and exactly three scenario overlays.
