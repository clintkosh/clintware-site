LinkedIn Company Cleaner

Clean out company Pages in bulk without touching people, schools, newsletters, or groups. Select companies or run through every company card found, then confirm once instead of approving each case.

Install

  1. Download and extract the ZIP.
  2. Open edge://extensions or chrome://extensions.
  3. Enable Developer mode.
  4. Choose Load unpacked and select the extracted folder.

Run

  1. Open LinkedIn’s company-following list.
  2. Scan, select companies, and set the run limit.
  3. Confirm once and watch progress on the page.
  4. Stop at any time.

Privacy

No account credentials, cookies, names, or company lists are sent to Clintware. The extension contains no analytics, external APIs, or remote code.

Compatibility notice. LinkedIn’s published rules prohibit browser extensions that automate activity on its site. This independent tool is not affiliated with or authorized by LinkedIn, may stop working when LinkedIn changes its interface, and may not qualify for Chrome Web Store or Edge Add-ons publication.
