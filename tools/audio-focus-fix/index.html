Audio + Focus Fix

A local Windows utility for isolating microphone feedback and stopping recurring script tasks from repeatedly opening visible windows and stealing focus.

Download Windows EXEView source
What it handles

One repair path for echo and focus theft.

The utility runs locally, elevates only when Windows requires it, and backs up settings before changing them.

AudioDiagnostic + repair

Echo isolation

Checks active input/output endpoints, microphone monitoring, loopback-style inputs, Jabra indicators, Hands-Free profiles, communications state, and Windows Audio.

WindowsFocus repair

Recurring task scan

Finds non-Microsoft frequent or script-based Scheduled Tasks, backs up their XML, and moves compatible tasks to hidden/background execution.

SafetyReversible

Backup first

Audio registry state and candidate task definitions are backed up before changes. Task definitions can be restored with the included restore mode.

Command modes

Target only what you need.

Clintware-AudioFocusFix-v2.exe --tasks-only
