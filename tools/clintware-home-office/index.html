Product truth

What exists today

Desktop

Tabbed Qt Writer alpha with rich text formatting and local files.

Formats

Open DOCX, HTML, text, and Markdown. Save DOCX, HTML, text, and Markdown. Export PDF.

Portable

A single-file browser editor that can run from Clintware or be saved and opened directly.

Installer

Windows packaging and Inno Setup definitions are in the project build path. A promoted public installer release still needs build/release verification.

Boundary: this is not presented as a complete Microsoft Office replacement. The current product is the first working Writer module and a suite architecture that is being expanded.
Suite path

One office shell, built module by module.

The aim is a coherent local suite, not three disconnected utilities. Shared file, print, template, recovery, and future plug-in services sit underneath each editor.

Working alpha

Roadmap

Presentations

Why build it

The opportunity is not “no free office suites exist.”

The test is whether there is room for an office tool that feels lighter, cleaner, more local, and less burdened by decades of interface history.

Local by default

Opening, editing, saving, and exporting should work without an account or cloud dependency.

Modern restraint

A focused interface with a document canvas first, rather than copying every ribbon and panel from incumbent suites.

Desktop + portable

The native app handles stronger format support; the browser editor covers lightweight use from one self-contained file.

Compatibility measured, not claimed

DOCX fidelity will be expanded against real regression files before stronger Office-compatibility claims are made.
