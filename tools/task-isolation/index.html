Task Isolation

Scheduled PowerShell and command jobs should run in the background, not appear on your desktop every minute. Task Isolation converts matching task actions to a true no-console worker while preserving the original schedule and task identity.

Download Windows EXEView source
WindowsNo-console

Actually removes the console

Uses a Windows GUI-subsystem helper plus CREATE_NO_WINDOW. This avoids the common failure where a Scheduled Task is marked Hidden but PowerShell or cmd still flashes and steals focus.

Scheduled TasksPreserving

Changes only the actions

Triggers, credentials, principal, conditions, and task settings stay intact. Matching running tasks can be restarted immediately under the background wrapper.

QQAuto-check

Integrated with Quillgeist Lite

QQ checks for desktop-interactive scheduled console actions as part of its local health path and repairs them when running with administrator privileges.
