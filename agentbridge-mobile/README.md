# AgentBridge Mobile

Expo source for the AgentBridge iPhone and Android remote-control app.  The immediately usable mobile alpha is the installable PWA at `agentbridge.clintware.com`; this native source is ready for device testing and later App Store / Play Store signing.

The mobile client intentionally does not attempt desktop-style privileged execution.  It pairs Nodes, sends Execution Packs, reviews results, and approves individual jobs.
