Remote MCP endpoint

https://quillgeist.clintware.com/mcp

Use this Streamable HTTP endpoint for ChatGPT Developer Mode testing and the Plugin Directory submission. The catalog v1 exposes context compaction and read-only aggregate impact retrieval. It does not expose remote Windows execution or private account access.

Tool 01

quillgeist_compact_context

Compacts prompt, transcript, log, or execution context. It removes consecutive repetition and preserves error-adjacent lines plus bounded beginning/end context.

curl -X POST https://quillgeist.clintware.com/api/v1/compact \
  -H "content-type: application/json" \
  -d '{"text":"your long context here","max_chars":24000,"record_aggregate_metrics":false}'

The response includes output, estimated raw/output tokens, estimated gross tokens removed, and reduction percentage. By default one aggregate product-impact event is recorded containing source/method and estimated token counts. Set record_aggregate_metrics=false to disable that Quillgeist aggregate event for the request.

Tool 02

quillgeist_product_impact

Returns read-only aggregate usage, execution, compaction, and estimated token-savings metrics for participating Quillgeist installs plus public API/MCP calls. Product-impact telemetry is retained for up to 730 days, so published totals represent retained participating telemetry rather than every installation or every historical request.

curl "https://quillgeist.clintware.com/api/v1/impact?days=30"
Restricted data

Do not send secrets or regulated data

The public compaction surface does not accept payment-card data, protected health information, government identifiers, passwords, API keys, access tokens, authentication secrets, MFA/OTP codes, or private keys. Common detected patterns are rejected before compaction. Redact restricted data before submitting task context.

Privacy boundary

What Quillgeist records

Submitted compaction text is processed to produce the response. Quillgeist product-impact telemetry does not intentionally store that submitted text or the returned compacted text. Aggregate telemetry can record the time, request source, compaction method, pass/compact status, and estimated token counts. Public API/MCP aggregate events do not contain a Quillgeist user, account, or device identifier.

Cloudflare may separately process ordinary network/security metadata needed to deliver and protect the service. See the Privacy policy for recipients, retention, and controls.

Catalog scope

ChatGPT Plugin Directory v1

The public ChatGPT plugin is intentionally bounded. It can compact context and retrieve aggregate Quillgeist impact. It cannot pair or control a Quillgeist Node, run local commands, modify local files, save credentials, or access a user's private Cloud account. Authenticated node/account delegation, if introduced later, requires a separate scoped authorization and permission model.
