Tool 01

quillgeist_compact_context

Compacts prompt, transcript, log, or execution context. It preserves error-adjacent lines, beginning/end context, and removes consecutive repetition before bounded truncation.

curl -X POST https://quillgeist.clintware.com/api/v1/compact \
  -H "content-type: application/json" \
  -d '{"text":"your long context here","max_chars":24000}'

The response includes output, estimated raw/output tokens, estimated gross tokens removed, and reduction percentage.

Tool 02

quillgeist_product_impact

Returns aggregate usage, execution, compaction, and estimated token-savings metrics for participating Quillgeist installs plus public API/MCP calls.

curl "https://quillgeist.clintware.com/api/v1/impact?days=30"
Privacy boundary

What the public API records

Submitted compaction text is processed to produce the response. Quillgeist application telemetry does not store that submitted text. Aggregate telemetry may record the time, request source, compaction method, pass/compact status, and estimated token counts. Public API/MCP aggregate events do not contain a Quillgeist user, account, or device identifier.

Normal infrastructure providers may process standard network/request metadata needed to deliver the service. Do not send credentials or secrets unless they are necessary for your requested transformation.

Catalog scope

Initial ChatGPT plugin candidate

The first public ChatGPT version is intentionally read-only. It can compact context and retrieve aggregate Quillgeist impact. It does not remotely execute actions on a user's Windows machine. Authenticated node/account delegation, if added later, will use a separate scoped authorization model and explicit permissions.
