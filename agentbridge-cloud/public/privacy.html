Quillgeist Privacy

Last updated: August 23, 2026
Public API/MCP summary: Quillgeist processes the task-specific text you explicitly submit to produce the requested compaction result. Quillgeist product-impact telemetry does not store that submitted prompt or context text. By default, a privacy-safe aggregate compaction event is recorded; callers can disable that event for a request by setting record_aggregate_metrics to false.

1. Scope

This policy describes Quillgeist services operated by Clintware, including the Quillgeist website, public API, remote MCP integration, ChatGPT plugin surface, and Quillgeist Cloud features. The installed desktop application may additionally use local data and account features controlled by the user's Quillgeist configuration.

2. Data processed by the public API and MCP tool

When you explicitly submit text to the public Quillgeist compaction API or MCP tool, Quillgeist receives that task-specific text in order to generate and return the compacted result. The submitted text is processed transiently for the request and is not intentionally written to Quillgeist product-impact telemetry or the Quillgeist aggregate metrics database.

The service does not request the user's full ChatGPT conversation history, profile, precise location, contacts, or unrelated account data. The tool operates only on the text the client or model explicitly sends for the requested compaction.

3. Aggregate product-impact telemetry

When aggregate metrics are enabled for a public compaction call, Quillgeist records a product-impact event that may include the event time, source channel, compaction method, compacted/pass status, estimated input token count, estimated output token count, and estimated tokens removed. Public API/MCP aggregate events do not contain a Quillgeist account ID, device ID, user ID, submitted prompt text, or returned compacted text.

Aggregate product-impact events are retained for up to 730 days and are automatically pruned from the product-metrics store after that retention window. Public statistics therefore represent retained participating telemetry, not every Quillgeist installation or request.

4. Your controls

For the public REST API and MCP compaction tool, set record_aggregate_metrics=false to prevent the Quillgeist aggregate compaction event for that request. The Windows application has separate telemetry and local-first controls. Because public API/MCP aggregate events are intentionally stored without a user or account identifier, Clintware generally cannot identify and selectively delete one person's already-recorded anonymous aggregate event. Questions or privacy requests can be directed to Clintware through the contact channel below.

5. Restricted data

Do not submit payment-card data, protected health information, government identifiers, passwords, API keys, authentication tokens, MFA/OTP codes, private keys, or other access credentials to the public Quillgeist API or ChatGPT/MCP compaction tool. These categories are outside the public plugin's intended function. Quillgeist applies server-side checks for common restricted-data patterns and rejects detected restricted data before compaction.

6. Windows and account telemetry

The Quillgeist Windows application and paired Cloud account can produce operational and product telemetry separately from the public API/MCP surface. Depending on the feature and user settings, this can include run status, duration, estimated token measurements, application version, errors after sanitization, and product-quality signals. Quillgeist supports telemetry configuration and local-first operation. When account/device telemetry contributes to public product-impact statistics, the global aggregate copy strips account and device identifiers.

7. Recipients and infrastructure providers

Clintware operates Quillgeist and processes the data necessary to provide the requested service. Quillgeist uses Cloudflare as an infrastructure and delivery provider; Cloudflare may process ordinary network and security metadata such as IP addresses, timestamps, HTTP headers, and diagnostic/security events as needed to operate and protect the service under Cloudflare's applicable service terms and policies. OpenAI/ChatGPT receives the model-readable result as part of the plugin interaction initiated by the user. Clintware does not sell submitted prompt content or public API/MCP aggregate telemetry.

8. Infrastructure logs and retention

Quillgeist does not intentionally write public API/MCP request bodies into application logs. Operational infrastructure may process or retain limited request/security metadata according to the configured Cloudflare service and Cloudflare's applicable retention practices. Quillgeist's own aggregate product-impact database follows the 730-day retention limit described above.

9. Public aggregate statistics

Quillgeist may publish aggregate product-impact statistics such as compaction counts, prompts processed, estimated tokens before and after compaction, estimated tokens saved, execution counts, and trends. These public statistics are aggregate measurements and are not intended to expose individual prompt content or identify an individual user.

10. Estimates

Token values described as estimated are approximations. They are not provider billing records and must not be treated as exact monetary savings unless a separate report uses authoritative provider usage and a frozen pricing snapshot.

11. Changes

This policy may change as Quillgeist evolves. The effective date above will be updated when material changes are published.

12. Contact

For privacy questions or requests, contact Clintware through clintware.com. Product support information is available at Quillgeist Support.
