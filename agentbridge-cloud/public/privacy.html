Quillgeist Privacy

Last updated: August 23, 2026
Public API/MCP summary: Quillgeist processes submitted text to return the requested compaction result. Quillgeist application telemetry does not store the submitted prompt or context text for public API/MCP compaction calls. Aggregate usage measurements may be recorded.

1. Scope

This policy describes Quillgeist services operated by Clintware, including the Quillgeist website, public API, remote MCP integration, and Quillgeist Cloud features. The installed desktop application may additionally use local data and account features controlled by the user's Quillgeist configuration.

2. Public API and MCP compaction

When you submit text to the public Quillgeist compaction API or MCP tool, the service receives that text in order to generate and return the compacted result. Quillgeist application telemetry is designed not to write that submitted text into its product-impact telemetry.

Aggregate telemetry for an API/MCP compaction may include the request time, source channel, compaction method, compacted/pass status, estimated input token count, estimated output token count, and estimated tokens removed. These aggregate API/MCP events are designed without a Quillgeist account, device, or user identifier.

3. Windows and account telemetry

The Quillgeist Windows application and paired Cloud account can produce operational and product telemetry separately from the public API/MCP surface. Depending on the feature and user settings, this can include run status, duration, estimated token measurements, application version, errors after sanitization, and product-quality signals. Quillgeist supports telemetry configuration and local-first operation.

4. Content and secrets

Do not submit passwords, private keys, authentication tokens, or other secrets unless they are required for the task and you intentionally choose to transmit them. Quillgeist does not sell submitted prompt content.

5. Infrastructure data

Quillgeist uses infrastructure providers, including Cloudflare, to deliver the service. Those providers may process ordinary network and request metadata needed to operate, secure, and deliver the service, such as IP addresses, timestamps, headers, and security/diagnostic information, according to their applicable terms and policies.

6. Public aggregate statistics

Quillgeist may publish aggregate product-impact statistics such as compaction counts, prompts processed, estimated tokens before and after compaction, estimated tokens saved, execution counts, and trends. These public statistics are aggregate measurements and are not intended to expose individual prompt content or identify an individual user.

7. Estimates

Token values described as estimated are approximations. They are not provider billing records and must not be treated as exact monetary savings unless a separate report uses authoritative provider usage and a frozen pricing snapshot.

8. Retention and deletion

Public API/MCP prompt content is not intentionally retained in Quillgeist product telemetry. Operational infrastructure logs may have separate retention controlled by the infrastructure provider or service configuration. Account holders may use available Quillgeist controls to manage local/account information and may contact Clintware regarding privacy questions.

9. Changes

This policy may change as Quillgeist evolves. The effective date above will be updated when material changes are published.

10. Contact

For privacy questions or requests, contact Clintware through clintware.com.
