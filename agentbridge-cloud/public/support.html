Quillgeist Support

Support for the Quillgeist Windows application, public REST API, MCP integration, and ChatGPT plugin is provided by Clintware.

Start here: API + ChatGPT developer documentation. For product or account questions, use the contact options published at clintware.com.

Before reporting a problem

  • Record whether the issue is in the Windows app, Cloud portal, REST API, or ChatGPT/MCP connection.
  • For API issues, include the endpoint, HTTP status, and a redacted example that contains no restricted data.
  • For ChatGPT plugin issues, note whether the MCP server connected and which Quillgeist tool was selected.
  • Do not send passwords, API keys, private keys, access tokens, payment-card data, government identifiers, protected health information, or unrelated private content.

Public v1 endpoints

https://quillgeist.clintware.com/api/v1
https://quillgeist.clintware.com/mcp

The public API/MCP v1 is a bounded production-review surface for context compaction and aggregate impact reporting. It does not provide remote Windows execution or private account access. The broader Windows application may separately contain alpha or prerelease capabilities.

Telemetry control

The public compaction API and MCP tool support record_aggregate_metrics=false to disable Quillgeist's aggregate compaction event for that request. Submitted prompt/context text is not intentionally stored in Quillgeist product-impact telemetry.
