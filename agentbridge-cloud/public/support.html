Quillgeist Support

Public distribution: starts local-only and does not use Clintware as its cloud runtime. See the self-host guide for optional cloud deployment.

Before reporting a problem

  • Record the Quillgeist version and operating system.
  • Run quillgeist doctor and redact unrelated private data before sharing diagnostics.
  • For self-hosted cloud issues, include your own deployment's HTTP status or logs, with secrets removed.
  • Never send passwords, API keys, access tokens, private keys, payment-card data, or MFA codes.

Clintware-hosted endpoints

The Clintware distribution domain does not provide public pairing, remote execution, telemetry ingestion, REST execution, or MCP execution. A 410 response on those old routes is intentional.
