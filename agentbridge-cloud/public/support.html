Quillgeist Support

Support for the Quillgeist Windows application, public API, MCP integration, and ChatGPT plugin is provided by Clintware.

Start here: API + ChatGPT developer documentation. For product or account questions, use the contact options published at clintware.com.

Before reporting a problem

  • Record whether the issue is in the Windows app, Cloud portal, REST API, or ChatGPT/MCP connection.
  • For API issues, include the endpoint, HTTP status, and a redacted example that does not contain credentials.
  • For ChatGPT plugin issues, note whether the MCP server connected and which Quillgeist tool was selected.
  • Do not send API keys, passwords, private keys, access tokens, or unrelated private content.
