Quillgeist Terms

Last updated: August 23, 2026
The Quillgeist public REST API and ChatGPT/MCP plugin v1 are bounded public service surfaces for context compaction and aggregate impact reporting. The broader Quillgeist Windows application and some Cloud capabilities may separately be identified as alpha or prerelease features.

1. Service

Quillgeist provides local-first AI workflow, context-compaction, execution, reporting, and related developer functionality. The public API/MCP v1 has a narrower scope than the Windows application: context compaction plus aggregate product-impact retrieval. Other Quillgeist features may evolve independently.

You are responsible for the content you submit, actions you authorize, connected providers and tools, credentials you configure, and compliance with applicable laws and third-party terms. Do not use Quillgeist to access or modify systems or data without authorization.

3. Public API and MCP

The public API and ChatGPT/MCP plugin v1 are intended for bounded context compaction and aggregate product-impact retrieval. The public compaction endpoint rejects detected restricted-data categories including common access credentials, payment-card data, government identifiers, and protected health information. Clintware may apply reasonable request limits and abuse protections needed to operate and secure the service.

4. Aggregate telemetry

Public compaction calls may record privacy-safe aggregate product-impact measurements as described in the Quillgeist Privacy policy. Callers can disable the Quillgeist aggregate compaction event for a request using the documented record_aggregate_metrics=false control.

5. Estimates

Token counts, savings, model alternatives, cost projections, and similar measurements labeled estimated are approximations. They are not guarantees, invoices, or authoritative provider billing data.

6. Local execution

Desktop execution features can make changes to a computer or workspace when the user has authorized those capabilities. Users should review permissions, backups, and generated changes appropriate to the task. The public ChatGPT plugin v1 does not authorize or expose remote execution on a user's Windows machine.
