Your operating method. Your machine. Your infrastructure.

Quillgeist keeps user-owned operating rules and local execution policy outside any one AI provider. The public build starts local-only, does not contain a Clintware server credential, does not pair to Clintware infrastructure, and has Quillgeist telemetry disabled by default.

Public isolation boundary
  • No default Quillgeist Cloud URL.
  • No Clintware MCP, admin, GitHub, or Cloudflare credential is distributed.
  • Telemetry is off unless the user explicitly enables it against their own configured instance.
  • Cloud pairing and remote execution require a cloud instance the user owns or controls.
  • The Clintware-hosted public account/device runtime is retired.
