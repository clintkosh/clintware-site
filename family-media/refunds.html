Refund and Cancellation Policy

Submitting an order request does not create a payment obligation. Paid work begins only after review and confirmed PayPal payment.

Before production starts

A paid order may be cancelled for a full refund before production begins, subject to any non-refundable amount clearly disclosed in the PayPal invoice.

After production starts

Once custom production begins, refunds are limited because labor and generation costs have been incurred. Clintware will first use the included revision process to correct work that does not reasonably match the approved direction.

Declined requests

If Clintware cannot accept a request and no acceptable original alternative is agreed upon, any payment collected for that request will be refunded through PayPal.

Disputes

Contact studio@clintware.com with the order reference before opening a PayPal dispute so the issue can be reviewed promptly.
