# OrgSynapse

OrgSynapse is a Clintware working MVP for a company-wide operational intelligence layer.

The first surface is CRM, but CRM is a view over one shared organizational state rather than an isolated database. Accounts, people, work, signals, and activity are represented as connected entities so Sales, Customer Success, Support, Product, Engineering, Operations, Finance, People, and leadership can operate from the same context.

## Working MVP

- Astro 7 static application.
- Local-first persistence in browser storage for a zero-account demo and self-contained testing.
- CRM account creation and health/ARR/renewal tracking.
- Cross-department work items tied to accounts and people.
- Signals feed for risks, opportunities, changes, and decisions.
- Organization graph view showing relationships among accounts, people, work, and signals.
- Role lens for department-specific filtering without duplicating data.
- Global search across the shared state.
- JSON export/import and deterministic seed reset.
- Activity ledger generated by every mutation.

## Security boundary

The browser MVP intentionally keeps demo data local and makes no external API calls. It is appropriate for synthetic/demo data only.

The production path is an adapter swap rather than a UI rewrite: replace the browser store with a tenant-scoped API backed by Cloudflare D1/Postgres and protect the application with Cloudflare Access or the customer's identity provider. Production requirements include tenant isolation, RBAC/ABAC, audit logs, encryption at rest/in transit, export controls, retention controls, and connector-level scopes.
