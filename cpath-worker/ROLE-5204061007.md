## Architecture decision
This is not a generic CRM. It is a **delivery accountability OS**:
1. single portfolio delivery view
2. mentor scorecards and 30-day coaching plans
3. leader action queue
4. shared leader/mentor perspectives
5. fellow exception/risk roll-up
6. PR-review, milestone, host-manager, and Commons commitments
7. weekly cadence and 1:1 contract
8. cross-pod pattern detection
9. curriculum change-request loop
10. browser-local seeded demo data only; no real CodePath data

## Evidence basis
- CodePath role description: outcomes, mentor cadence, 1:1s, escalation path, portfolio risk, curriculum signals.
- CodePath mentorship guidance: dependable commitments, timely feedback, open communication, independence.
- Anthropic Building Effective Agents: prefer simple composable workflows; add agentic complexity only where it earns the tradeoff.
- Anthropic context engineering / evals: high-signal context and visible evaluation criteria.
- Management support: specific, direct, human feedback and regular 1:1 coaching.
